# CLAUDE.md

Project context, the CV data model, design tokens and the CI/CD flow all live in @AGENTS.md — read
that first. It is the single source of truth; don't duplicate it here.

## Skills

- **`update-cv`** — add or amend a work, education or volunteer entry in `src/data/cv.ts`

## Things that bite

- The design is settled. Fix bugs and accessibility within it; don't redesign it.
- All user-facing copy is **Norwegian**. Code identifiers are English.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin — never hand-edit it.
- Use the theme tokens (`bg-surface`, `text-primary`, `text-secondary`) from `@theme` in
  `src/index.css`, never raw hex. Animations come from `src/lib/animations.ts`, not inline variants.
- `public/CNAME` is what keeps magnhildmyskja.no working. Don't remove it.
- **You cannot push to `main`** — it's protected. Branch, open a PR, merge once CI is green.
